# OnlyQuick.com landing page

A static React + Vite landing page for the acquisition of **OnlyQuick.com**, designed as a premium dark editorial experience for quick commerce, express delivery, logistics, courier, last-mile, and on-demand companies.

## Local development

```bash
pnpm install
pnpm dev
```

The local development server runs at the URL printed by Vite.

## Production build

```bash
pnpm check
pnpm build
pnpm preview
```

The production files are emitted to `dist/public`.

## Vercel deployment

Import the repository into Vercel with the following settings, or allow `vercel.json` to apply them automatically:

```bash
vercel --prod
```

The project is frontend-only. It has no database, backend routes, server-side secrets, or required environment variables. The static output directory is `dist/public`.

## Conversion links

The primary inquiry CTA opens `mailto:owner@onlyquick.com?subject=OnlyQuick.com%20acquisition`. The secondary secure-purchase CTA opens `https://unstoppabledomains.com/d/onlyquick.com` in a new tab.
